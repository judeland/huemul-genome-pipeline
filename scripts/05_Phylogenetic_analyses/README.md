# Huemul phylogenetic analyses

This directory contains the scripts and parameter documentation used for the
nuclear and mitochondrial phylogenetic analyses of *Hippocamelus bisulcus*.

## Directory structure

```text
05_Phylogenetic_analyses/
├── README.md
├── nuclear/
│   ├── run_iqtree.sh
│   └── rename_orthofinder_tree.py
└── mitochondrial/
    ├── MAFFT_online_parameters.md
    └── run_iqtree.sh
```

## Nuclear phylogeny

The nuclear phylogeny uses the concatenated alignment of single-copy
orthologues generated by OrthoFinder:

```text
SpeciesTreeAlignment.fa
```

### `nuclear/run_iqtree.sh`

Runs maximum-likelihood phylogenetic inference with IQ-TREE using automatic
model selection and 1,000 ultrafast bootstrap replicates.

### `nuclear/rename_orthofinder_tree.py`

Uses the OrthoFinder `SpeciesIDs.txt` mapping to replace numerical tree-tip
identifiers with species names.

## Mitochondrial phylogeny

The mitochondrial dataset contains:

- the normalized *H. bisulcus* mitochondrial genome;
- selected Cervidae mitochondrial references;
- *Bos taurus* as the outgroup.

The reference mitogenomes and associated metadata are prepared with:

```text
00_References/mitochondrial/download_mitogenomes.py
```

### Mitochondrial alignment

The complete mitochondrial genomes were aligned using the MAFFT online server.

The settings are documented in:

```text
mitochondrial/MAFFT_online_parameters.md
```

### `mitochondrial/run_iqtree.sh`

Runs maximum-likelihood phylogenetic inference with IQ-TREE using automatic
model selection, 1,000 ultrafast bootstrap replicates, and *Bos taurus* as the
outgroup.

## Workflow relationships

```text
OrthoFinder single-copy-orthologue alignment
└── nuclear IQ-TREE analysis
    └── species-tip renaming

Reference mitogenomes
+ normalized H. bisulcus mitogenome
└── MAFFT online alignment
    └── mitochondrial IQ-TREE analysis
```

Software versions used in the huemul analysis are documented in the
repository-level `SOFTWARE.md`.
