# Mitochondrial genome alignment with MAFFT

The mitochondrial phylogenetic dataset comprised 16 complete mitochondrial
genomes prepared with `download_mitogenomes.py`.

Multiple sequence alignment was performed using the MAFFT v7 online server.

## Input

`mitochondrial_phylogeny/input/mitochondrial_genomes.fasta`

## Parameters

- Strategy: automatic selection
- Direction adjustment: enabled
- Remaining options: MAFFT online defaults

## Output

The aligned multifasta was downloaded as:

`mitochondrial_phylogeny/mafft/mitochondrial_genomes_aligned.fasta`
