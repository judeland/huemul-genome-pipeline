# Reference resources

This directory contains scripts used to download and prepare the external
reference resources required by the nuclear, mitochondrial, annotation, and
comparative-genomics workflows.

These references are auxiliary inputs. The nuclear and mitochondrial huemul
genomes were assembled de novo from Oxford Nanopore reads.

## Directory structure

```text
00_References/
├── nuclear/
│   ├── download_odocoileus_reference.sh
│   └── prepare_nuclear_reference.sh
├── proteomes/
│   └── download_and_deduplicate_reference_proteomes.py
└── mitochondrial/
    └── download_mitogenomes.py
```

## Nuclear reference

### `nuclear/download_odocoileus_reference.sh`

Downloads the *Odocoileus virginianus* Ovbor_1.2 reference assembly
(GCF_023699985.2) and its associated annotation files from NCBI.

The reference is used for:

- reference-guided scaffolding with RagTag;
- annotation transfer with LiftOn;
- reference-based assembly assessment with QUAST.

### `nuclear/prepare_nuclear_reference.sh`

Generates nuclear-only versions of the *O. virginianus* reference FASTA and
GFF3 files by removing mitochondrial record NC_015247.1 and its associated
annotations.

The complete downloaded reference files are retained unchanged.

Downloaded genomic resources are stored under `references/genomic`; the
nuclear-only FASTA and GFF3 are stored in `references/genomic/nuclear`.

The nuclear-only reference prevents mitochondrial genes from being
transferred to nuclear mitochondrial DNA segments (NUMTs) during LiftOn
annotation.

## Reference proteomes

### `proteomes/download_and_deduplicate_reference_proteomes.py`

Surveys annotated Cervidae genome assemblies available from NCBI and selects
one annotated assembly per taxon, prioritizing:

1. RefSeq over GenBank;
2. chromosome-level assemblies;
3. assemblies with more annotated protein-coding genes.

The script downloads the selected proteomes and retains the longest protein
isoform per gene.

Because NCBI holdings may change, the script also prepares the exact accession
set used in the huemul comparative-genomics analysis. These standardized
proteomes are subsequently used as input for OrthoFinder.

The `orthofinder/` folder therefore contains the exact accessions used in this
study, which reproduce the reported comparative analysis. The survey, in
contrast, reflects the annotated Cervidae available in NCBI at run time and may
include additional genomes in the future, so a later re-run can legitimately
differ from the original set.

The representative *Hippocamelus bisulcus* proteome generated by the
annotation workflow is added separately.

Downloaded and standardized proteomes are stored under
`references/proteomic`.

## Mitochondrial references

### `mitochondrial/download_mitogenomes.py`

Downloads the mitochondrial genome references used for phylogenetic analysis,
including:

- selected complete mitochondrial genomes from NCBI RefSeq;
- mitochondrial replicons retrieved from annotated chromosome-level genome
  assemblies;
- *Bos taurus* as the outgroup.

The script adds the locally assembled and normalized *H. bisulcus*
mitochondrial genome and generates:

- a 16-sequence mitochondrial multifasta;
- a metadata manifest containing species names, accessions, and sequence
  sources.

Individual reference mitogenomes are also retained under
`references/mitochondrial/individual`; the *H. antisensis* file is used for
mitochondrial-read enrichment.

The resulting multifasta is used as input for the MAFFT mitochondrial-genome
alignment.

## Downstream relationships

```text
O. virginianus genome
├── RagTag scaffolding
├── LiftOn annotation
└── QUAST assessment

Reference proteomes
└── OrthoFinder comparative genomics

H. antisensis mitogenome
└── Mitochondrial read enrichment

Reference mitogenomes
└── Mitochondrial phylogenetic analysis
```

Software versions used in the huemul analysis are documented in the
