# Mitochondrial genome annotation with MITOS2

Structural annotation of the assembled mitochondrial genome was performed with
MITOS2 v2.1.0 on the Galaxy platform.

## Input

The complete circular mitochondrial genome generated with PMAT2.

## Parameters

- Genetic code: vertebrate mitochondrial code
- NCBI translation table: 2
- Remaining options: Galaxy/MITOS2 defaults

## Outputs retained

- Mitochondrial annotation in GFF format
- NCBI feature table
- Tabular annotation summary
- Protein-coding gene sequences
- Protein sequences
- Gene-order file

The retained MITOS2 annotation files are included in the mitochondrial genome
dataset deposited in Zenodo.
